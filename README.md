# VF-MotorController
Designed and simulated a motor control system for electric vehicle traction, focusing on a 3-phase induction motor driven by a variable voltage/frequency inverter (Simulink). The system employs Volts/Hertz (V/F) control for speed regulation and considers a "Torque Demand based Speed Control" layer (conceptual, not modeled) where accelerator input would determine the target speed. A PID controller manages the inverter's output to achieve this target while maintaining a constant V/F ratio. Operational safety was addressed through implemented voltage and frequency limits. The simulation also included regenerative braking to capture and rectify deceleration energy for potential battery recharge. This project showcases a V/F control approach with a perspective on torque-based speed command.
